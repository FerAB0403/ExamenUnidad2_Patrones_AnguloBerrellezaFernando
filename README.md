Nombre del proyecto asignado: 
Gestión del tráfico y flotas urbanas

Descripción:
Este programa en C# simula un taxi de 15 asientos usando dos patrones clave: una "instancia" llamada ChecadorTrafico que usa el patrón Singleton (asegurando que solo haya uno de él controlando todo) y una "piscina" de asientos (AsientoPool) que usa el patrón Object Pool (para reutilizar los 15 asientos sin tener que crearlos o destruirlos). En la simulación, el Checador (Singleton) inicia la ruta, los pasajeros "toman" asientos del Pool, y en las paradas (y al final) los asientos se "liberan" y regresan al Pool, listos para el siguiente viaje.

1. Abrir la carpeta "src".
2. Despues descargar la carpeta llamada "ExamenU2".
3. Ya descargada la carpeta, se debe de abrir y dar doble clic en la solución (ExamenU2.sln).
4. Una vez inicializado el programa seleccionar la opción "Iniciar" para ejecutar el código.
